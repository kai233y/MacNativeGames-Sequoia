# 改动与验证

## 2026-10-30 旷野之息花屏

用户报告全程花屏；代理观察到菜单紫色块与纹理异常。
关闭异步渲染编码后问题仍在，着色器编译日志没有报告失败。
修正 Metal 3 间接纹理与缓冲的逐通道 `useResource` 声明；异步渲染将资源声明排入同一工作线程的队列，在绘制前执行。
只缓存地址而省略资源声明的两个快捷路径暂时关闭；uniform 声明指向实际快照缓冲。
首个诊断候选误把采样器交给 `useResource`，Metal 验证报错；最终版本区分采样器与 MTLResource。
用户随后确认花屏消失、画面正常。未宣称完整通关或长时间稳定性验证。

原理参考：[Apple：间接参数缓冲资源的驻留与使用声明](https://developer.apple.com/documentation/metal/tracking-the-resource-residency-of-argument-buffers)。
