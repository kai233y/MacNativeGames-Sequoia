# 两个 App 的设置

## 王国之泪 1.2.1

关闭游戏后重新打开，在启动器调整输出分辨率（例如 `1920x1080`、`2560x1440`）、比例、全屏、窗口大小与画面填充。
先选择比例，再填写分辨率；选择比例会自动更新尺寸。
游戏内 1 切换空间超分，3 切换画面模式，4 开关性能信息。
这款 App 的 1 键不是设置面板入口。

## 旷野之息 1.6.0

游戏中按 1 打开设置，画面页可以调整分辨率、画面比例、锁帧、性能信息和帧率图；选择保存到下次启动。
补帧与新 MetalFX 时间抗锯齿在本 Metal 3 版不可用。
输入页可开启鼠标模式；按键设置页可修改映射。

| 操作 | 默认按键 |
|---|---|
| 移动 / 视角 | WASD / 方向键 |
| 确认、对话、拾取 | E、回车 |
| 返回、冲刺 | Shift、退格 |
| 跳跃 / 攻击 | 空格 / G |
| 举盾、锁定 / 拉弓 | Q / Option |
| 希卡石能力 / 投掷 | F / R |
| 蹲下 / 望远镜 | Control 或 C / V |
| 背包菜单 / 地图 | Esc 或 I / Tab 或 M |
| 十字键 左/上/右/下 | 2/3/4/5 |

鼠标模式打开后：移动鼠标转视角，左键攻击，右键拉弓，中键举盾。
上述键鼠映射为 BOTW 新运行时默认值；不能当作旧 TOTK App 的映射。
